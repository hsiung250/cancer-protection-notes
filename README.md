# 癌症保障自學筆記

這是可直接部署到 GitHub Pages 的靜態網站版本，不需要安裝任何套件。

## 檔案結構

```text
index.html   網站入口
styles.css   視覺樣式與響應式版面
app.js       自我檢核與學習進度
og.png       社群分享預覽圖
.nojekyll    GitHub Pages 靜態發布設定
```

## 使用方式

直接開啟 `index.html` 即可瀏覽。上傳到 GitHub 後，可在 Repository 的 **Settings → Pages** 選擇 `main` 分支與根目錄發布。
